Phawx ON 1.0 — first release.

A small native performance tuner for Windows handhelds and laptops with a QAM-style overlay and AutoTDP.

- TDP control on AMD (SMU) and Intel (PL1/PL2), EPP, hybrid P/E core control, CPU clock caps
- GPU clock control for AMD, NVIDIA and Intel
- AutoTDP ("Phawx ON"): EPP 0 plus the lowest CPU/GPU clocks that hold your FPS target
- Opens from the tray, a button combo of your choice, a swipe from the top-right corner, or Ctrl+Alt+P

Requirements: [PawnIO](https://pawnio.eu) with its signed modules for hardware control, and Intel PresentMon for AutoTDP. Install to Program Files if you want Start with Windows. See the README for details.

Untested on real hardware at release time — please report issues.
